Pokémon that live above your Claude Code prompt

A free Claude Code plugin. Your party roams a tiny pixel world while you work: they run when Claude is busy, cheer when your tests pass, faint when they fail, and evolve as you ship.

/plugin marketplace add JinHang02/claude-code-pokemon
/plugin install pokemon@claude-code-pokemon

Run both inside Claude Code, then start a new session. Needs Claude Code 2.1.287 or newer and a terminal with 24-bit color.

They react to your work

Nothing to set up. Your party watches what Claude is doing and reacts on its own.

Only real failures make them faint. A grep that finds nothing isn't a failure, so a plain command has to fail three times in a row before anyone keels over. Leave Claude idle for five minutes and they doze off.

Even the spinner joins in, and each turn closes with a Poké Ball:

✻ Searching tall grass… (17m 46s · thinking)
◓ Caught for 18m 2s

Raise them into legends

Every Pokémon in your party earns XP from the work you and Claude get done.

Claude finishes a reply +2
A test run passes +5
A commit goes through +10

They evolve at the same level as in the games: Charmander at 16, Charmeleon at 36. Stone and trade evolutions happen at Lv 30, regional forms evolve the way their region does, and gender matters where it does in the games.

905 Pokémon, 424 alternate forms, and a 1 in 32 chance of a shiny on every catch.

Twenty landscapes, on your clock

Meadow, hills, mountains, lake or forest: a new one every hour, at dawn, day, dusk or night by your local time. This shows the time of day it is for you right now.

Commands

Type them straight into Claude Code.

  • /pokemon <name>Pick your lead, spelled exactly: shiny gengar, galarian mr mime
  • /pokemon add [name]Grow your party to three; no name catches a random one
  • /pokemon remove [name]Release one; with no name, never your lead
  • /pokemon partyLevels, XP to go, and who evolves when
  • /pokemon boxYour PC box: Pokémon you caught while the party was full
  • /pokemon deposit <name>Move a party member into the box, level and all
  • /pokemon everstone <name>Stop (or allow again) a Pokémon's evolution
  • /pokedexEverything you've seen, per generation, plus your shinies
  • /pokemon-play <animation>Watch any animation now: evolve, wild, dusk lake…
  • /pokemon offPut them in their Poké Balls; /pokemon on brings them back

A battle HUD for your status line

Optional and separate from the plugin: a status line script with your model as a nametag, the context window left as an HP bar, and your effort as a level. Setup is in the README.

Questions

Does it slow Claude Code down?

No. It draws about 20 frames a second while things move and drops to 5 when nothing does, and it never touches Claude's work.

Does it send my code anywhere?

No. It only downloads sprites and evolution data, then caches them. It looks at which commands Claude runs and whether they succeed, and none of that leaves your machine.

I installed it and nothing shows up.

It's a Claude Code mod, and mods are on by default from Claude Code 2.1.287, so update Claude Code if you're on an older version and start a new session. Then run /plugin: the line under the tabs should list pokemon among the active mods. Settings such as disableAllHooks, --safe-mode or an organization's policy can turn mods off. The party is drawn in a terminal, not in the Desktop app or the VS Code chat panel.

Which terminals work best?

iTerm2, Ghostty, kitty, WezTerm and Windows Terminal draw the pixel art crisply. In the VS Code or Cursor terminal, set terminal.integrated.minimumContrastRatio to 1. macOS Terminal.app works but shows thin lines between rows.
